# Sorting-Visualizer

Sorting visualizer built with React with js. Algorithms implemented inlcude MergeSort, BubbleSort, and SelectionSort. Animations done with DOM manipulation

## Built With
- React
- Js
- CSS

## Features
- Array Size Change
- 3 Sorting methods
- New Array Generation
